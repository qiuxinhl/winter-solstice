# 两个人的云端小屋

这是已接入前端的云端服务源码，尚未创建云资源、尚未部署、尚未开通200GB容量。当前公开网站仍显示“本机留言”和“共享相册尚未连接”。

支持两部手机共享留言、原图上传下载、视频在线播放和拖动进度、16MiB分片上传、显示上传进度和取消、私有文件临时访问链接。文件不经过GitHub仓库。R2可容纳超过100GB；容量上限由服务端设置并检查，示例为200GB十进制，不能理解为已购买或免费赠送。

## 费用与前置条件

需要使用者自己的Cloudflare账号，开通Workers、D1和R2。开通R2通常需要绑定付款方式，不能承诺免费。2026-11-10核对官方：https://developers.cloudflare.com/r2/pricing/ 。标准存储每GB每月0.015美元，免费10GB，每月存满200GB时存储费约2.85美元，操作量与其他服务按实际用量计费，下载流量免费。价格和免费额度以开通时官方说明为准。最大容量限制不会替代账单限额或费用提醒。

## 部署步骤（等待账号和费用确认后执行）

1. 安装当前稳定版Node.js，使用 `npx wrangler login` 登录自己的账号。
2. 执行 `npx wrangler d1 create our-little-world`，保存返回的数据库ID。
3. 执行 `npx wrangler r2 bucket create our-little-world-private`。保持存储桶私有，不打开公开访问。
4. 将 `wrangler.example.jsonc` 复制为 `wrangler.jsonc`，填写数据库ID，并按实际需要设置容量上限。
5. 执行 `npx wrangler d1 execute our-little-world --remote --file schema.sql --config wrangler.jsonc`。
6. 为这个小屋生成一个随机的64位十六进制口令，通过 `npx wrangler secret put ROOM_SECRET --config wrangler.jsonc` 交互输入；不要写入口令文件或提交到GitHub。
7. 执行 `npx wrangler deploy --config wrangler.jsonc`。取得HTTPS服务地址，在网页的“连接共享空间”中输入地址及小屋口令。两个人使用相同地址与口令。

## 使用边界

- 私有文件使用12小时有效的临时链接，链接在有效期内等同访问凭据，请只在两个人之间使用。口令保存在各自浏览器，不进入网页源码或JSON记录备份。更换口令会使已有临时链接失效。
- 只有知道口令的人可访问云端，两个使用者共享同一个小屋权限，双方均可撤下留言和删除文件。称呼不是独立账户登录。
- 本机留言与云端留言分别保存，接入后不会未经确认将本机留言上传。现有JSON备份包含本机留言，不包含云端原文件；请通过下载原文件自行另存。
- 云端留言每次显示最新500条，历史数据仍在D1内；相册展示已完成上传的文件。图片视频是否可直接播放取决于手机支持的编码，建议使用JPEG/PNG和H.264/AAC的MP4。
- 单文件分片最多10000片（约156GiB），总容量由MAX_STORAGE_BYTES限制。不要把容量上限设得低于已存文件。上传期间需保持页面打开；网络失败可重新选文件上传，当前版本没有断点续传。取消会释放当前上传占用，已完成文件保留。
- 关闭网页或系统强制中止可能留下未完成的上传。服务每小时清理连续24小时没有上传新片段的暂存文件，每次最多100个；分片成功时会续期，正常上传不因创建时间过早而被清理。建议另外开启R2的未完成分片生命周期清理。暂存记录也计入容量，避免反复上传绕过上限。
- 开发检查可使用Cloudflare本地模拟器；尚未登录或未接入R2/D1前，不能宣称云端存储、跨手机同步或真实100GB上传已经验证。
